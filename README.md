### AIS++ v1.0.0
Notes: 
This version implements the ABCD method and the ttt-scheme analytically as found in Charle Antoine's thesis [1].
A few issues have been found, in particular in the computation of the classical action, and in general the calculations
were hard to keep track of, motivating the move to a simplified theoretical model in combination to numerical ODE solvers.
